# New Feature Playbook

Goal:

Deliver a new feature that is maintainable, usable, tested, and deployable.

## Recommended Sequence

### 1. Tina

Determine:

- Scope
- Success criteria
- Required participants

### 2. Alice

Evaluate:

- Architectural impact
- Dependencies
- Risks
- Design options

### 3. Uma

Define:

- User experience
- User flows
- Accessibility requirements

### 4. Bob

Produce:

- Implementation plan
- Code changes

### 5. Rita

Review:

- Code quality
- Security
- Maintainability

### 6. Teo

Validate:

- Test strategy
- Edge cases
- Regression risks

### 7. Dave

Assess:

- Deployment impact
- Monitoring requirements
- Operational concerns

## Definition of Done

- Architecture approved
- UX considered
- Implementation completed
- Review completed
- Test coverage identified
- Deployment concerns addressed
