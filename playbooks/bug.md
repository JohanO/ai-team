# Bug Playbook

Goal:

Understand, fix, and prevent recurrence.

## Recommended Sequence

### 1. Teo

Reproduce the issue.

Identify:

- Steps to reproduce
- Expected behavior
- Actual behavior

### 2. Alice

Evaluate:

- Root cause
- Architectural implications

### 3. Bob

Implement a fix.

### 4. Rita

Review the fix.

### 5. Teo

Verify:

- Original bug resolved
- No regressions introduced

### 6. Dave

Review operational impact if applicable.
